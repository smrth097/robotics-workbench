# Robotics Workbench

Interactive **3D robotics simulation workbench** with **Three.js** (ES modules), **RK4** Lagrangian dynamics, **DH** industrial manipulators (2-DOF Planar, 3-DOF Spatial, ABB IRB 120, KUKA KR 6 R700, UR5e, 4-DOF SCARA, and Single SE(3) Frame), **PyTorch Neural IK** training/inference, one-click 3D demos, and **GitHub Actions** automation.

- **Repo:** https://github.com/smrth097/robotics-workbench
- **Live Demo:** https://smrth097.github.io/robotics-workbench/

## Local Preview
```bash
python3 -m http.server 8080 --bind 127.0.0.1

```
Open `http://127.0.0.1:8080`, and enable **GitHub Pages** under **Settings -> Pages** (`main` branch, `/ (root)`).

Setup & Local Preview

Serve over HTTP rather than file:// because the app uses native ES modules.

for f in js/*.js; do node --check "$f"; done
python3 -m http.server 8080

Performance Mode Selection

Use the Perf dropdown in the workbench bar to switch between Ultra, Balanced, and Lite rendering modes based on your GPU and battery needs.

Exports & Console Debugging

  • Export URDF XML or DH parameter JSON from the workbench controls, or share pose state via URL hash.
  • Open DevTools (F12) -> Console to inspect window.__wbTools.
window.__wbTools
window.__wbTools?.setPerfTier?.("balanced")

Setup & Local Preview

Run python3 -m http.server 8080 and open http://localhost:8080. Validate JS with node --check before pushing.

Performance Mode Selection

Use the Perf dropdown in the top-right bar to switch between Ultra, Balanced, and Lite rendering modes.

Exports & Console Debugging

Export URDF XML or DH JSON from the controls, and inspect window.__wbTools in DevTools Console (F12).
